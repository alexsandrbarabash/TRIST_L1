Pipeline

Один push запускає весь процес

Кожен етап має одну чітку відповідальність, а помилки зупиняють доставку до того, як вони потраплять у хмару.

  1. 01

    Перевірка коду

    HTMLHint і Stylelint знаходять проблеми у розмітці та стилях.

  2. 02

    Збірка образу

    Docker створює компактний nginx-образ із готовою сторінкою.

  3. 03

    Доставка

    GitHub Actions може опублікувати образ для оновлення VM.

Готово до запуску

Одна команда — однакова сторінка всюди.

Зберіть контейнер локально та відкрийте застосунок на порту 80.

docker build -t cloudflow . && docker run --rm -p 80:80 cloudflow
